# Screen Blueprint

## 1. Home
Purpose:
- show today's plan
- streak
- weak skills
- quick start

Widgets:
- welcome card
- current level chip
- daily target card
- weak area cards
- continue practice button

## 2. Practice
Purpose:
- choose skill and activity

Sections:
- filters: level, skill, unit
- list of available activities
- suggested activities
- quick resume

## 3. Activity Player
Purpose:
- render one exercise at a time

Needs:
- title
- prompt
- instructions
- answer input area
- submit button
- feedback panel
- retry action
- save result

## 4. Review
Purpose:
- revisit mistakes and weak areas

Sections:
- due for review
- recurring mistake tags
- retry by skill
- saved phrases / notes

## 5. Progress
Purpose:
- show performance trends

Sections:
- CEFR progress
- skill breakdown
- completed units
- weakest tags
- recent streaks

## 6. Settings
Purpose:
- choose level
- daily goal
- theme
- speech settings
- content pack controls
