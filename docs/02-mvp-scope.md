# MVP Scope

## In scope
- Authentication: none for v1 (offline-first)
- Local database with Room
- JSON-based lesson content imported on first launch
- Home screen with daily plan
- Practice screen by skill and level
- Review screen with mistakes and spaced retry
- Progress screen with skill/domain trends
- Settings screen with current level and daily goal
- Speaking transcription using Android speech recognition
- Listening activity playback with local or bundled audio references

## Out of scope for v1
- Cloud sync
- Teacher dashboard
- AI scoring from external APIs
- Advanced pronunciation scoring
- Multiplayer or community features

## Success criteria
- User can complete 1 full daily session
- User can practice reading, writing, listening, and speaking
- User can revisit weak areas
- User progress is persisted locally
