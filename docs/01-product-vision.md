# Product Vision

## Product idea
An Android app for deliberate English practice focused on helping learners improve through targeted repetition and feedback instead of random exercises.

## Core principles
1. Practice weak areas on purpose.
2. Track recurring mistakes.
3. Separate reusable app engine from content.
4. Design the content layer so new CEFR levels can be added without rewriting the app.
5. Support four core skills:
   - Reading
   - Writing
   - Listening
   - Speaking

## Target rollout
### Phase 1
Pilot with B2 and C1 content.

### Phase 2
Expand to B1.

### Phase 3
Expand to A1 and A2.

## Main user loop
1. User selects level or takes placement test.
2. App assigns a daily deliberate-practice plan.
3. User completes tasks by skill.
4. App stores attempts, mistakes, and weak tags.
5. Review queue resurfaces weak patterns.
6. Progress is updated by level, skill, and domain.
