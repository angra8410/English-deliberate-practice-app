# English Deliberate Practice App Blueprint

This is a **project blueprint** for an Android Studio app built with **Kotlin + Jetpack Compose + Room**.

## Goal
Build an English deliberate-practice app that starts with **B2 → C1** and is designed to scale later to:
- A1
- A2
- B1
- B2
- C1

The app should support:
- Reading
- Writing
- Listening
- Speaking
- Error tracking
- Review queues
- Progress tracking
- Daily practice planning

## Recommended v1 scope
- Levels: B2 and C1
- Skills: Reading, Writing, Listening, Speaking
- Features:
  - Daily plan
  - Practice by skill
  - Mistake review
  - Progress dashboard
  - Offline-first local content
  - Speech-to-text for speaking prompts
  - Audio playback for listening tasks

## Recommended stack
- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- Room
- ViewModel + StateFlow
- SpeechRecognizer
- TextToSpeech
- ExoPlayer or Media3 for listening audio

## Notes
This zip is **not a full runnable production app** yet. It is a **strong Android Studio-ready blueprint** with:
- architecture
- package structure
- core model ideas
- starter Kotlin scaffolding
- data schema templates
- content JSON examples
- roadmap
